## Mobile-first app layout
Build frontend UI mobile-first from 320px upward. On phones, use compact spacing and app-style primary navigation in a fixed, safe-area-aware bottom tab bar; keep primary content visible early without unnecessary scrolling. Preserve the established desktop layout at larger breakpoints and verify responsive changes across phone, tablet, and desktop widths.
